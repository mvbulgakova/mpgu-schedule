# Telegram-бот абитуриента МПГУ

Бот помогает поступающим в приёмную кампанию: отвечает на вопросы и считает
дополнительные баллы за индивидуальные достижения. Расписание из бота убрано
(парсеры/данные расписания остаются в репозитории, но к боту не подключены).

## Как работает

Запускается без внешнего хостинга — через GitHub Actions long-polling
(`.github/workflows/bot-poll.yml`): каждый запуск опрашивает `getUpdates` ~55 минут и
отвечает почти мгновенно, затем выходит; крон перезапускает. Реализация —
`scraper/telegram_bot.py`.

> Файлы `worker.js` / `wrangler.toml` в этой папке — прежний вариант на Cloudflare Worker
> (бот расписания на вебхуках). Актуальный бот — polling-версия выше.

## Команды

- `/start`, `/help` — приветствие и меню тем.
- `/abitur` — меню частых тем (сроки, документы, ВИ/ДВИ, БВО/СПВО, доп. баллы, общежитие,
  целевое, льготы, контакты) — детерминированные ответы без LLM.
- `/bally` — калькулятор дополнительных баллов (детерминированный, пошаговый).
- любой свободный вопрос — AI-ответ (Claude Haiku 4.5), заземлённый на базу знаний
  `scraper/abitur/knowledge.md` (без выдумок; при нехватке данных — контакты приёмки).

## Секреты (Settings → Secrets → Actions)

- `BOT_TOKEN` — токен бота от @BotFather.
- `ANTHROPIC_API_KEY` — уже используется в `scrape.yml`; проброшен и в `bot-poll.yml`.
  Без него меню и калькулятор работают, отключается только AI-ответ на свободные вопросы.

## Обновление данных приёмной кампании

Факты и правила версионируются в репозитории:
- `scraper/abitur/knowledge.md` — база знаний для FAQ (с датой актуальности);
- `scraper/abitur/achievements.py` — таблица баллов для калькулятора (раздел 9 Правил
  приёма + Приложение 7).
