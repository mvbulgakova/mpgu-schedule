# Калькулятор шансов (вариант C) — дизайн

**Дата:** 2026-07-02
**Статус:** утверждён к проработке (вариант C выбран пользователем)
**Контекст:** замена «калькулятора шансов» из архивного YandexGPT-бота
(`archive/yandexgpt-abitur-bot`: `score_predictor.py`) на достоверную версию. Требование
пользователя: максимально точные оценки, ошибаться нельзя, «не гарантия» проговаривается.

## Что отвечает бот

Абитуриент вводит свои ЕГЭ (предметы + баллы) → бот показывает:
1. **Подбор программ** — только те, где перечень ВИ совпадает с его предметами
   (источник: `pk26_obrazovatelnyeprogrammy` — официальный перечень программ с ВИ;
   старый бот предлагал программы с чужими ЕГЭ — это исправляется именно здесь).
2. **Живая позиция 2026** (основной сигнал): по спискам epk25 — «с суммой N ты сейчас
   был бы ~M-й из K подавших; бюджетных мест X (КЦП-2026); баллы текущего топ-X: от Z».
3. **Исторический ориентир** (вторичный, явно помеченный): проходные прошлых лет по этой
   программе — диапазон и по годам.

## Источники исторических проходных (проверено 2026-07-02)

Архив mpgu.su (`/postuplenie/priemnaya-komissiya/priemnyie-kampanii-20hh-2014-godov/`):
- **«Конкурс и проходной балл в YYYY году»** — официальные HTML-таблицы по программам
  (проверено на 2019: факультет / код направления / программа+форма / конкурс / проходной,
  ~300 строк; есть страницы минимум за 2015, 2018, 2019, 2020 + отдельно филиалы).
- **«Приказы о зачислении»** (2015–2021) и **«Сведения о зачислении»** (2022–2023) — из них
  проходной вычисляется точно: минимальная сумма баллов среди зачисленных на основные
  бюджетные места (без БВИ и квот), плюс распределение (медиана/квартели).
- Хабы 2024/2025 — аналогичные разделы (уточнить структуру при реализации).
- URL-шаблоны старого бота не работают (страницы находятся только по реальным ссылкам из
  хабов) — обходчик идёт от хабов по ссылкам, а не угадывает URL.

**Ответ на вопрос «можем ли выудить баллы ранее 2025»: да** — официальные таблицы с ~2015
и приказы/сведения о зачислении с 2015 по 2023+ доступны и парсятся.

## Метод оценки (честный, без ложной точности)

1. **Серия по программе**: проходные за доступные годы; матчинг программ по коду
   направления + названию программы + форме (переименования — таблица соответствий).
2. **Не одна цифра, а диапазон**: последние 3–5 лет → min–max и значение прошлого года;
   тренд применяется только при стабильной серии (≥3 точки, умеренный разброс). Годы
   старше ~2019 — только как контекст (сменились правила: приоритетная система с 2023,
   пилот БВО-2026, программы 4→5 лет).
3. **Корректор мест**: КЦП-2026 по программе (файлы `pk26_kcp*`) против мест прошлого
   года — рост мест давит балл вниз, сокращение — вверх (качественная пометка).
4. **Живой сигнал 2026 доминирует** по мере хода кампании: из epk25 — число заявлений,
   баллы топ-K (K = бюджетные места без квот), позиция абитуриента с его суммой.
5. **Подача**: «Проходной 2023–2025: 231–242 (2025: 238). Мест в 2026: 25 (было 20).
   Сейчас в топ-25 списка баллы от 219. С твоими 231 ты ~18-й.» + дисклеймер «это не
   гарантия и не обещание; проходной-2026 станет известен только после зачисления».

## Приватность
Из приказов прошлых лет (могут содержать ФИО до ~2021) сохраняются ТОЛЬКО агрегаты по
программе (мин/медиана/квартели/кол-во). Никаких персональных данных в data-ветке.

## Архитектура (по образцу списков epk25)

- `scraper/fetchers/history_fetcher.py` — обход архивных хабов по ссылкам (не по шаблонам).
- `scraper/parsers/passing_score_parser.py` — таблицы «Конкурс и проходной балл»;
  `scraper/parsers/enrollment_order_parser.py` — приказы/сведения о зачислении (агрегаты).
- `scraper/parsers/programs_parser.py` — перечень программ с ВИ из
  `pk26_obrazovatelnyeprogrammy` (какие ЕГЭ на какую программу) + КЦП-2026.
- `scraper/build_admissions_index.py` — единый `admissions/programs.json` в data-ветке:
  `{program_key: {направление, программа, форма, ВИ:[...], места_2026, история:{год:балл},
  диапазон, тренд-метка}}`. Разовый прогон истории + редкое обновление.
- Бот: команда `/shansy` — пошаговый ввод предметов/баллов (кнопки предметов + ввод чисел),
  далее merge трёх сигналов (подбор → живой epk25 → история). Детерминированно, без LLM.

## Не делаем
- Точечный «прогноз-2026 = X» без диапазона; регрессию на всей истории 2014–2025 как у
  старого бота (несопоставимость правил); хранение персональных строк из приказов;
  «приграничные» списки школ (нет основания в Правилах-2026).

## Открытые вопросы к реализации
- Формат «Сведений о зачислении» 2022–2025 (страницы/файлы) — уточнить при реализации.
- Сопоставление программ между годами при переименованиях — таблица соответствий, вести
  вручную при расхождениях.
