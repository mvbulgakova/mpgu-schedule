# Перенос абитур-бота на новый username

Username существующего бота в BotFather сменить нельзя — создаём нового бота и
переносим токен. Бонус: старый токен остаётся боту расписания
(@schedule_mspu_bot + cloudflare-worker-bot), конфликт «два бота на одном
токене» исчезает.

## Шаги

1. В **@BotFather**: `/newbot` → имя: `Абитуриент МПГУ` → username, например
   `mpgu_abitur_bot` (на 2026-07-17 выглядел свободным; варианты:
   `abitur_mpgu_bot`, `mpgu_priem_bot`, `postuplenie_mpgu_bot`).
2. Скопировать новый токен.
3. GitHub → Settings → Secrets and variables → Actions → **BOT_TOKEN** →
   Update → вставить новый токен.
4. Actions → **Telegram Bot (polling)** → Run workflow (старый ран отменится
   сам, новый подхватит новый токен).
5. Настроить нового бота в BotFather (тексты ниже): `/setcommands`,
   `/setdescription`, `/setabouttext`, по желанию `/setuserpic`.
6. Старому @schedule_mspu_bot поставить `/setdescription`:
   «Помощник абитуриента переехал: @mpgu_abitur_bot».

⚠️ Пользователи старого бота не переносятся автоматически — бот не может писать
тем, кто его не запускал. Подписки на позицию (`subs.json` в actions/cache)
относятся к старому боту; после переезда подписчикам нужно оформить их заново.

## Тексты для BotFather

### /setcommands
```
start - главное меню
spisok - моя позиция: прохожу ли я и на что
follow - следить за изменением позиции
unfollow - отключить слежение
shansy - подбор программ по баллам ЕГЭ
vybor - консультация по выбору направления
bally - калькулятор доп. баллов
sroki - сроки и ближайшие дедлайны
help - помощь
```

### /setdescription (до /start)
```
Помогаю поступающим в МПГУ:
🔎 /spisok — позиция в конкурсных списках по уникальному коду
🔔 слежение — пришлю сообщение, когда позиция изменится
🧮 /shansy — подбор программ под твои ЕГЭ + проходные прошлых лет
➕ /bally — расчёт доп. баллов за достижения
📅 /sroki — дедлайны кампании 2026
Отвечаю и на свободные вопросы по Правилам приёма.
```

### /setabouttext (профиль, коротко)
```
Помощник абитуриента МПГУ: списки, подбор по ЕГЭ, доп. баллы, сроки приёма 2026.
```
