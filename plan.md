## Что сделано

### Scraper
- [x] Параллельный обход всех 16 институтов
- [x] 5 форматов входных данных: PDF, DOCX, Excel, Google Sheets, Nextcloud
- [x] Три уровня PDF-парсинга: pdfplumber → camelot → Gemini vision
- [x] Нормализация расписания (дни, время, типы занятий)
- [x] Hash-based инкрементальный апдейт (CHANGED_ONLY)
- [x] Fallback на кеш при нулевом результате
- [x] Аномали-детектор (groups_dropped, parser_broken)
- [x] Поддержка всех форматов МПГУ-таблиц в PDF (1a, 2, 3, journalism, shifted header)
- [x] Multi-group DOCX (колонки по группам, "101 ГРУППА")
- [x] normalize_time: дефис, точка, newline-разделённые времена
- [x] Дедупликация групп — одна группа в нескольких файлах объединяется
- [x] link_min_year фильтр — для journalism обрезает архивные ссылки до 2024+
- [x] **Финальный санитайзер** (`sanitize_groups`) — единая очистка всех парсеров перед записью:
      удаление точных дублей пар, сортировка по времени, извлечение подгруппы из текста,
      чистка аудитории (`ауд. 403` → `403`, фикс двойного префикса `ауд. ауд.`), достройка slot.
      Покрыт тестами (`scraper/tests/test_sanitize.py`), есть backfill (`scraper/backfill_sanitize.py`).

### PWA
- [x] Выбор института → выбор группы → просмотр расписания
- [x] Переключение чётная/нечётная неделя (с автоопределением текущей)
- [x] Офлайн-режим через IndexedDB
- [x] Сохранение выбора в localStorage (Zustand persist)
- [x] Адаптивная вёрстка (mobile-first, max-w-2xl)
- [x] Поиск по группе в GroupSelector (с кнопкой ×, счётчиком, группировкой по степени)
- [x] Подсветка текущего занятия ("Сейчас" badge + indigo ring)
- [x] Скролл к сегодняшнему дню при открытии
- [x] Автоопределение чётности текущей недели при запуске

### CI/CD
- [x] Автосбор 2 раза в день (08:00 и 20:00 МСК)
- [x] Ручной запуск для отдельного института
- [x] Деплой PWA на GitHub Pages при push в main
