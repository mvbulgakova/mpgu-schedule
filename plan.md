## Что сделано

### Scraper
- [x] Параллельный обход всех 16 институтов
- [x] 5 форматов входных данных: PDF, DOCX, Excel, Google Sheets, Nextcloud
- [x] Три уровня PDF-парсинга: pdfplumber → camelot → Gemini vision
- [x] Нормализация расписания (дни, время, типы занятий)
- [x] Hash-based инкрементальный апдейт (CHANGED_ONLY)
- [x] Fallback на кеш при нулевом результате
- [x] Аномали-детектор + GitHub Issues
- [x] Поддержка всех форматов МПГУ-таблиц в PDF (1a, 2, 3, journalism, shifted header)
- [x] Multi-group DOCX (колонки по группам, "101 ГРУППА")
- [x] normalize_time: дефис, точка, newline-разделённые времена

### PWA
- [x] Выбор института → выбор группы → просмотр расписания
- [x] Переключение чётная/нечётная неделя (с автоопределением текущей)
- [x] Офлайн-режим через IndexedDB
- [x] Сохранение выбора в localStorage (Zustand persist)
- [x] Адаптивная вёрстка (mobile-first, max-w-2xl)

### CI/CD
- [x] Автосбор 2 раза в день (08:00 и 20:00 МСК)
- [x] Ручной запуск для отдельного института
- [x] Деплой PWA на GitHub Pages при push в main

## Что хочется сделать

### Scraper

- [ ] **ЗФО-парсер** — расписания с датами вместо дней недели (заочники)
- [ ] **Поддержка `.doc`** — часть старых файлов в бинарном формате Word
- [ ] **Дедупликация групп** — если группа встречается в нескольких файлах, объединять расписания, а не дублировать записи
- [ ] **childhood / international** — разобраться почему файлы недоступны; возможно, нужна другая точка входа на сайте МПГУ
- [ ] **preschool / languages** — только 2 группы каждый; скорее всего остальные в image-based PDF; нужен Gemini API Key в CI
- [ ] **Кодирование подгрупп** — сейчас `subgroup` всегда null; парсер умеет видеть "(п/г 1)", но не записывает

### PWA

- [ ] **Поиск по группе** — поле фильтра в GroupSelector (актуально для journalism с 251 группой)
- [ ] **Показ текущего занятия** — подсветить слот, который идёт прямо сейчас
- [ ] **Push-уведомления** — напоминание за N минут до пары (Service Worker)
- [ ] **Избранные группы** — закрепить несколько групп (преподаватель ведёт в разных)
- [ ] **Экспорт в iCal** — добавить расписание в Google/Apple Calendar
- [ ] **Тёмная тема** — TailwindCSS dark mode
- [ ] **Android-приложение** — в репо есть `android/` заготовка, можно WebView-обёртку

### Инфраструктура

- [ ] **Кастомный домен** — прописать CNAME в `deploy-pwa.yml`
- [ ] **Мониторинг** — уведомление в Telegram/email если scrape.yml падает
- [ ] **Версионирование данных** — хранить не только последнее расписание, но и историю изменений (diff по группам)
- [ ] **API** — REST/JSON-API поверх data-ветки для сторонних клиентов (бот, виджет)
